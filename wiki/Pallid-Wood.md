### Pallid Log

<img src="../src/main/resources/assets/sift_unbound/textures/block/pallid_log.png" width="64" height="64" style="image-rendering: pixelated" alt="Pallid Log texture">

Pale blue-white bark from the Sift's 'pale tree-like structures'. Strip it with an axe.

| Property | Value |
|---|---|
| ID | `sift_unbound:pallid_log` |
| Hardness | 2 |
| Best tool | Axe |
| Where to find | Pallid trees |
| Drops | Pallid Log |
| Tags | `#minecraft:overworld_natural_logs`, `#sift_unbound:pallid_logs` |

**Used to make**: Pallid Wood

### Pallid Planks

<img src="../src/main/resources/assets/sift_unbound/textures/block/pallid_planks.png" width="64" height="64" style="image-rendering: pixelated" alt="Pallid Planks texture">

Pale, almost white planks. Uses the cherry wood sounds. Works for every recipe that takes planks.

| Property | Value |
|---|---|
| ID | `sift_unbound:pallid_planks` |
| Hardness | 2 |
| Best tool | Axe |
| Where to find | Crafting |
| Drops | Pallid Planks |
| Tags | `#minecraft:planks` |

**How to get it**

- Crafting (shapeless): any `sift_unbound:pallid_logs` -> **4x Pallid Planks**

**Used to make**: Pallid Button, Pallid Door, Pallid Fence, Pallid Fence Gate, Pallid Pressure Plate, Pallid Slab, Pallid Stairs, Pallid Trapdoor
