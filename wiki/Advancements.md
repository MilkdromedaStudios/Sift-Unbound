A new advancement tab, **The Sift Unbound**, with a Sift-grass background. It doubles as a guide: each advancement's
description explains the mechanic it is about, so the tab teaches the Sift as you meet it (26 in all).
The mod's own `sift_unbound:sift_event` trigger lets datapacks react to the same moments (humming or playing the
melody, an echo golem waking a portal, shearing a nuzzle, the Endure and Thrive tides, enraging the sifters).

| Advancement | How to get it, and what it teaches | Frame |
|---|---|---|
| **The Sift Unbound** | Craft an Echo Tuner from echo shards found in ancient cities | task |
| &nbsp;&nbsp;↳ **Singer in Stone** | Find Chiseled Soulshale, carved with a singer, in an ancient city chest | task |
| &nbsp;&nbsp;↳ **Hum Along** | Sneak and use the Echo Tuner to hum the Sift's melody and see its notes | task |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Note Block Machine** | Play the melody (F♯ A C♯ B A E C♯ F♯) on eight note blocks by a Warden Portal. Each right note sends up a soul | goal |
| &nbsp;&nbsp;↳ **Resonance** | Wake a Warden Portal with the Sift's melody: use an Echo Tuner on its frame, or play the melody on note blocks | goal |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Beyond the Frame** | Step through the Warden Portal into the Sift | challenge |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;↳ **Jelly Squeeze** | Collect Blub Jelly, which blubs shed after a soak in ichor | task |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;↳ **Squeak Squeak** | Breed two Blubs with Lullaby Blooms | task |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;↳ **Sift Explorer** | Visit every region of the Sift | challenge |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;↳ **Is That a Rock?** | Feed a Slabber Teal Sprouts. Slabbers doze through the Endure Tide, tucked in like part of the ground | task |
